# Game Testing Portfolio

Portfolio de testes de jogos e relatórios de QA.

Este repositório reúne testes realizados em builds de jogos, com foco em identificação de bugs, análise de desempenho, usabilidade, colisões, progressão e experiência do jogador.

## Objetivo

Registrar playtests de forma clara e organizada, mantendo um histórico técnico dos problemas encontrados e do feedback enviado aos desenvolvedores.

## Áreas analisadas

- Bugs e comportamentos inesperados
- Desempenho, FPS e stuttering
- Crashes e estabilidade
- Colisões e limites de cenário
- Controles e usabilidade
- Interface e experiência do usuário
- Clareza de objetivos e progressão
- Tutoriais e orientação ao jogador
- Gameplay e mecânicas

## Estrutura dos relatórios

Sempre que possível, os relatórios incluem:

- Jogo e versão testada
- Data do teste
- Plataforma
- Hardware utilizado
- Descrição do problema
- Passos para reproduzir
- Resultado esperado
- Resultado observado
- Severidade
- Evidências
- Observações adicionais

## Ambiente de testes

- CPU: AMD Ryzen 5 5500
